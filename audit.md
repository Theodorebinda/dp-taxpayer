## 8. Summary of Required Work

- **Http Layer**: Relocate and harden HttpClient, standardize responses, centralize auth headers & error handling.
- **React Query**: Provide configured QueryClient with 401 logic, create domain-specific hooks (`useApplications`, `useApplicationMenus`, `usePrefetchMenus`, `useMarkMenuVisited`).
- **State Split**: Move server data out of Zustand; create dedicated UI stores (`ui-store.ts`, `navigation-store.ts`) limited to layout + selected IDs.
- **Components**: Refactor Home, Sidebar, Menu layouts/cards to consume hooks, add prefetch + optimistic mutations, implement missing Grid layout.
- **Prefetch**: Use `queryClient.prefetchQuery` on hover for both apps and menus.
- **Tests**: Add unit/integration suites for hooks and key UI flows.
- **Docs**: Record migration steps for stores and new provider integration.

This report satisfies Step 0 (audit). Next steps: implement foundational infra (HttpClient, Query hooks, UI stores) before refactoring components.
